# SAMPLE | American Craft Burgers & Grill

A website for **SAMPLE**, an artisanal American craft burger restaurant located in New York (SoHo) and Austin, TX.

Designed with a modern, borderless visual aesthetic, fluid micro-interactions, responsive layouts, and zero visual clutter.

## 🍔 Features

- **Borderless Modern Architecture**: Ambient lighting, subtle elevations, and 20px glassmorphism without boxy borders or unnecessary pills.
- **Interactive 3D Hero Burger**: Perspective tilt responsive to cursor motion with high-resolution food photography.
- **Curated Burger Collection**: Filterable menu by category (All, Prime Smashes, Wagyu, Fiery, Plant-Based) with details quick-view.
- **The Burger Lab**: Live interactive burger builder where users stack ingredients (buns, prime patties, artisanal cheeses, toppings, and emulsions) and watch the burger visually construct in real-time with live price calculation.
- **Order Bag Drawer**: Slide-in cart system with real-time tax calculation, item quantity controls, and checkout flow.
- **Table Reservation System**: Native HTML5 `<dialog>` modal with date/time pickers and party size options.
- **Responsive & Accessible**: Semantic HTML5, ARIA labels, responsive across mobile, tablet, and desktop screens.

## 🛠️ Built With

- **HTML5** (Semantic structure, native `<dialog>`)
- **CSS3** (CSS custom properties, glassmorphism, fluid `clamp()` typography, `@starting-style` transitions)
- **Vanilla JavaScript** (ES6+, state management, live visual layer rendering, cart system)
- **Google Fonts** (`Plus Jakarta Sans` & `Syne`)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve using any static file server:

```bash
# Using Python
python -m http.server 8080

# Or using Node
npx serve .
```
